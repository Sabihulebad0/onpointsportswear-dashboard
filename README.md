# Sports Admin

React admin panel for the sports ecommerce API.

## Run

Start MongoDB, then the backend:

```powershell
cd ..\sports_backend
npm run seed
npm run dev
```

In this folder:

```powershell
npm install
npm run dev
```

Open `http://localhost:5173`.

Admin login (after seed): `admin@sports.com` / `admin123`

The Vite dev server proxies `/api` to `http://localhost:5000`.
